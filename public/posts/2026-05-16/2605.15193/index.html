Aligning Latent Geometry for Spherical Flow Matching in Image Generation

为图像生成中的球面流匹配对齐潜在几何

导读摘要：这篇论文抓住了 latent flow matching 里一个很容易被忽略、但影响很大的问题：VAE 潜变量和高斯噪声其实都集中在高维“薄球壳”上，可传统方法却用欧氏直线把两者连接起来，导致训练路径频繁穿过几乎不真实出现的球内区域。作者进一步证明，decoder 对 token 的“方向”远比“长度”更敏感，于是提出把每个 latent token 投到固定半径球面上、把噪声也变成球面先验、只微调 decoder，并将线性插值改成球面插值 SLERP。这样整条流动路径始终留在球面上，训练目标天然只剩角向运动。方法不改扩散骨干、也不依赖额外编码器，却在 ImageNet-256 上对多种 tokenizer 和不同规模模型都稳定提升 FID，并显著加快达到同等质量所需的训练步数。

一、问题不在模型骨干，而在 latent 空间里“走错了路”

这篇工作最重要的判断是：latent flow matching 的瓶颈，不一定来自生成器能力不足，而可能来自训练路径与潜空间几何结构不匹配。

标准 latent flow matching 的做法很直接：令噪声端点 (z_0 \sim \mathcal{N}(0, I))，数据端点 (z_1 = E(x))，然后在两者之间做线性插值 [ z_t = (1-t)z_0 + t z_1 ] 并训练模型去预测对应速度。这套做法默认 latent 空间是“平直欧氏空间”，直线就是自然路径。

但作者指出，这个默认前提对 VAE latent 并不合适。原因有两层：

  1. 高斯噪声本身在高维里就集中在薄球壳上。
  2. 经过 tokenizer 预处理后的数据 latent token，范数也同样集中在薄球壳上。

也就是说，起点和终点都靠近某个球壳，但线性路径却会穿过球体内部。中间那些半径更小的位置，既不像噪声端，也不像真实数据端，模型却被迫花大量监督去学习它们。

这正是论文的核心出发点。下图把这个几何失配讲得很清楚：左边是传统直线路径，右边是作者提出的球面路径；后者不是换了新的生成架构，而是换了 latent 里更合理的“走法”。

如果只看直觉，这个改动像是在“几何上更优雅”；但论文真正有价值的地方在于，它没有停留在直觉层面，而是继续追问：这些径向变化到底重要吗？

二、为什么作者敢把半径“压扁”：语义主要在方向里

论文最有说服力的证据之一，是它把每个 latent token 拆成了两部分：

  • 半径：(r = |z|)
  • 方向：(\hat z = z / |z|)

于是 token 可写成 (z = r \hat z)。

接下来作者做了一个很关键的交换实验：从同类图像中取相同空间位置的 token，把“方向”和“半径”分别与邻居交换，再送入 decoder 看图像变化。这个实验本质上是在问：

  • 只改长度，不改方向，图像会不会大变？
  • 只改方向，不改长度，图像会不会大变？

结论非常明确：方向变化几乎决定了感知和语义变化；半径变化的影响明显更小。

也就是说，如果保持 anchor 的方向、换掉半径，解码结果通常还和原图很接近；但如果保持半径、换掉方向，结果往往就接近“整 token 被替换”的效果。作者还用 LPIPS 和 DINOv2 距离做了量化，支持这一点。

这一步非常关键，因为它让后面的设计不再只是“让路径贴合分布”，而是进一步变成：

  • 既然 decoder 主要依赖方向，
  • 那么训练就不该把太多精力浪费在半径伸缩上，
  • 最合理的做法就是固定半径，只学习方向变化。

这也是整篇论文从“几何观察”走向“方法设计”的转折点。

三、方法主线：球面投影、球面先验、decoder 微调、SLERP 训练

作者的方法并不复杂，但几步之间咬合得很紧，最好按完整流水线来理解。

1. 逐 token 球面投影

对 encoder 输出的每个 latent token，做 L2 归一化后再缩放到固定半径，统一投到半径为 (\sqrt d) 的球面上。这里 (d) 是 token 通道维度。

这样做后，每个 token 的长度都被固定下来，保留的主要是方向信息。它不是对整张图的 latent 一次性投影，而是逐 token 独立投影，因此更贴合原本的 token 化生成范式。

2. 把高斯噪声也变成球面先验

数据端被投到球面后，噪声端也必须对齐到同样几何，否则两端仍不一致。作者做法是：从高斯采样后，只保留其径向投影得到的方向，再映射到相同固定半径的球面上。于是噪声端和数据端都落在同一球面支撑集上。

3. 冻结 encoder，只微调 decoder

球面投影会改变 latent 分布，原 decoder 未必能完美适应。因此作者不重训整个 tokenizer，而是：

  • 冻结 encoder
  • 只微调 decoder 若干个 epoch

这样 decoder 学会从球面 latent 稳定重建图像，而 encoder 保持不变。这一步开销远小于重新训练一套 VAE，也避免了引入额外表示对齐目标。

4. 用 SLERP 替代线性插值

当噪声 token 和数据 token 都位于同一球面上后，就不再使用欧氏线性插值，而改用 SLERP（球面线性插值）。SLERP 的关键性质是：

  • 路径是球面上的最短测地线；
  • 任意时刻都留在固定半径球面上；
  • 路径变化天然是“角向”的，而不是径向缩放。

这样一来，训练目标不再鼓励模型去预测不必要的半径变化。

5. 速度目标只保留切向分量

因为 SLERP 路径始终在球面上，其速度天然位于球面的切空间中。也就是说，模型要拟合的目标速度本质上是纯角向速度，不含径向分量。这个变化非常重要：它把模型监督从“方向 + 长度同时变化”收缩为“只沿球面转向”。

总结成一句话，作者做的不是换 backbone，而是把 latent 训练坐标系和流动路径一起改造成球面几何，使监督信号与 decoder 真正敏感的信息对齐。

论文首页的总览图很好地概括了这条主线：先把端点放到同一球面，再沿球面弧线推进，而且这种改动本身就带来了更快的 FID 收敛。

四、几何证据：为什么线性流匹配会浪费大量监督

方法之所以成立，不只是因为“球面更自然”，而是因为作者系统证明了：线性流匹配确实在训练中花了很多力气去学不太重要的径向变化。

先看半径统计。论文统计了高斯噪声以及多种 tokenizer 的 per-token 范数，既看原始编码，也看进入 flow training 前的预处理结果。结论是：

  • 不同来源的 token 范数都具有很小的变异系数；
  • 说明它们天然集中在较薄的球壳上；
  • 常规预处理能部分拉近尺度，但不能统一把所有 tokenizer 严格放到同一球面；
  • 球面投影则能直接把所有 token 的半径固定下来。

这也是论文里所谓“预处理只是部分对齐，投影才是统一对齐”的含义。对于 FLUX.2 和 VA-VAE，预处理后范数已经接近高斯壳；但对 REPA-E FLUX.1，这种尺度差异仍然明显。换言之，仅靠已有标准化流程，不足以解决几何失配。

论文还从另一个角度说明问题：即便起终点半径已经接近，只要走的是欧氏直线，中间路径仍会向球体内部塌陷。原因很简单，在高维中两个随机方向通常接近正交，因此弦的中点半径往往显著小于端点半径。作者实证发现，线性路径会明显偏离真实端点常出现的半径区间。

更致命的是，作者进一步把线性流匹配的速度目标分解成：

  • 径向分量
  • 切向分量

结果发现，在路径靠近两端时，径向分量常常占到总速度的很大比例，约一半甚至更多。 也就是说，模型训练的很大一部分监督，其实是在要求它“把 token 往里拉、再往外推”，而这恰恰不是 decoder 最敏感、也不是最承载语义的变化。

这幅分解图几乎就是全文方法动机的直接证据：如果训练目标中长期存在很大的径向分量，而语义又主要在方向上，那么标准线性路径就是在错误地分配模型容量。球面投影 + SLERP 的本质，就是把这部分监督从目标中删除掉。

顺带一提，作者还给出了一个额外表格来支撑方法判断：不同 tokenizer 的范数统计说明“薄球壳”现象不是偶然，而是相当普遍的 latent 结构特征。

此外，文中还有一处支持性总结材料，强调的也是同一条逻辑链：先看到 latent 支撑集近似球壳，再结合 decoder 对方向更敏感这一事实，最后自然推出“固定半径、只学角向变化”这一设计。

五、实验结果：收益来自几何对齐，而不只是 decoder 微调

实验部分最值得关注的，不是某一个绝对最优数字，而是方法在不同 tokenizer、不同 backbone、相同训练协议下都能稳定占优。

首先，在 ImageNet-256 上，相比原始线性 latent flow matching，球面方法能更快达到同等 FID，且继续训练后最终结果更好。作者特别强调，在 SiT-B/2 配合 FLUX.2 VAE 的设置下，球面方案达到 vanilla 版 FID=30 所需步数约少了 2.2 倍，这说明它不只是“最终上限更高”，训练过程本身也更高效。

表格结果也支持这一点：在保持扩散架构不变、匹配训练设置的前提下，球面路径通常能带来更低的 FID。

更重要的是，这种提升不是局限在单一 tokenizer 上。作者在 FLUX.2、VA-VAE、REPA-E FLUX.1 等不同 tokenizer 上都观察到一致改进；而且从 SiT-B 到 SiT-XL，这个收益也能延续。也就是说，提升并不依赖于某个特定潜空间或某个特定模型规模。

论文还做了一个很关键的控制实验，用来排除“是不是只是 decoder finetune 带来的收益”。作者把 vanilla 流程和球面流程中训练出的 decoder 互换，结果两边 FID 都变差。这说明：

  • decoder 并不是单独变强了；
  • 它是和对应 latent 几何一起适配出来的；
  • 真正起作用的是latent 支撑集、decoder 适配、训练路径三者的共同对齐。

这点非常重要，因为它把论文贡献从“一个有效技巧”提升成了“一个完整几何方案”：不是只改重建器、也不是只改插值方式，而是同时改造端点分布与中间路径，让整个 flow matching 过程都在一致的球面坐标系里进行。

六、这篇论文真正带来的启发

这篇工作的价值，不只是提出了一个性能更好的 latent flow matching 变体，更重要的是它提醒了一个常被忽略的事实：

生成模型训练的不只是数据本身，还在学习数据所在坐标系中的运动方式。

过去很多工作关注：

  • tokenizer 重建误差高不高，
  • backbone 大不大，
  • 表示对齐损失强不强，

而这篇论文把注意力拉回到一个更基础的问题：latent 空间到底长什么样，模型又是否沿着与其匹配的几何路径在学习。

从这个角度看，作者的贡献可以压缩成三句话：

  1. 发现问题：VAE latent 和高斯噪声都近似分布在薄球壳上，线性路径会系统性穿过不自然区域。
  2. 给出依据：decoder 对方向远比对长度敏感，说明径向运动并不是主要语义载体。
  3. 提出改法：把 token 投到固定半径球面，用球面先验和 SLERP 训练，让监督集中到纯角向流动。

它的优点也很鲜明：

  • 不改扩散/流匹配骨干；
  • 不需要额外 encoder；
  • 不依赖新的表示对齐损失；
  • 可兼容不同 tokenizer 家族；
  • 训练和效果上都有实质收益。

如果要用一句话概括本文的方法主线，那就是：不是让模型更复杂，而是让模型在更对的几何里学习。
